# UX prototype walkthrough

The [standalone prototype](file:///Users/ramazantalgatov/Downloads/TenderGuard.html) uses synthetic records and local
HTML/CSS/JavaScript interactions. Open the downloaded HTML in a browser; GitHub's
source view is not the running prototype. It has no API, storage, authentication,
model calls or real compliance analysis. Refresh resets temporary interactions.

| Step | Screen / action | Intended behavior illustrated |
| --- | --- | --- |
| 1 | Overview, then Company documents | Company evidence inventory and intended profile workflow. |
| 2 | Tender upload | Browser-only synthetic file selection, mock validation and explicit upload/unsupported outcomes. |
| 3 | View synthetic report | Met/unmet/unknown findings and missing-evidence explanations. |
| 4 | Open tender and company sources | Both sides of the evidence relationship; excerpts are authored examples. |
| 5 | Record review note | Human assessment distinct from machine output; persistence simulated. |
| 6 | Revise evidence / Analysis runs | New mock run retains previous rows. |
| 7 | Ask TenderGuard | Authored cited-answer/uncertainty format; entered questions invoke no model. |
| 8 | Privacy & settings | Simulated route block and unavailable model; no actual network-policy enforcement. |

## Alignment issues

| Prototype detail | Core boundary | Action |
| --- | --- | --- |
| Roadworks example | Provisional IT/office-equipment pilot | Align or clearly retain as a generic illustration. |
| PDF/DOCX/TXT validator | Text PDF/DOCX requirements | Remove TXT or explicitly approve an extension. |
| Proposed 25 MB limit | No measured agreed limit | Confirm through TG-T03. |
| C3 commercial-data label | Current SQL public/private only | Confirm policy vocabulary/mapping; C3 is not an implemented enum. |
| Analyst account label | Owner/member/viewer product roles | Map the persona to member/owner. |
| Privacy/report output | Synthetic simulation | Present intended behavior rather than completed controls or model results. |

Ramazan coordinates the actual walkthrough and records participant tasks,
observations, completion, status interpretation and resulting changes. Keyboard,
focus, readable status labels, live announcements and responsive checks remain to

guide, not evidence of a completed user study.
